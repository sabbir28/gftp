User Guide & Command Reference

Detailed documentation for all gftp CLI commands, options, and configuration keys.

Direct Remote Git Cloning & Auto Push

gftp allows you to clone a remote Git repository and automatically upload it directly to an FTP destination directory in a single command:

# Clone git project and push to target remote FTP folder /htdocs
gftp --git https://github.com/sabbir28/gftp.git --ftp /htdocs

# Perform dry-run preview for remote git project
gftp --git https://github.com/sabbir28/gftp.git --ftp /htdocs --dry-run

Command Reference Matrix

Command Supported Flags Description
gftp init --preset, --host, --user, --pass, --port, --remote-dir, --git Initializes .gftp/config in current folder with credentials or preset
gftp config show, set <key> <value> Inspect or modify configuration settings dynamically
gftp test None Validates FTP server connection, authentication, and directory write permissions
gftp status --git <url> Compares local HEAD commit SHA against remote synced SHA and prints file change table
gftp push / gftp sync --git <url>, --ftp <dir>, --clean, --dry-run, --force, --all Uploads pending modified/added files, handles deletions, updates remote SHA state
gftp clean-remote --force / -y Recursively wipes all remote files and subdirectories from target FTP server path
gftp log None Displays historical deployment transfer records

Configuration File Options (.gftp/config)

Key Default Value Description
host ftpupload.net FTP Server Hostname or IP address
port 21 FTP Service Port
user mseet_42012618 FTP Account Username
pass *(Encoded default)* FTP Account Password
remote_dir /htdocs Remote root directory on target FTP server
passive true Enable Passive Mode (PASV) transfers
delete_remote false Remove remote files deleted locally
