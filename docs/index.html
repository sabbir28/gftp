Sync Only Git Changes via FTP.

gftp is a lightweight, high-performance C++ CLI for Windows. It tracks your local Git HEAD commit against the deployed remote state, uploading only modified or added files with real-time transfer progress.

Why Use gftp?

Designed for speed, safety, and seamless Git workflow integration.

⚡

Git Differential Sync

Calculates git diff against the last deployed remote commit SHA (.gftp_state). Re-uploading unchanged files is a thing of the past.

🚀

Native WinINet C++ Engine

Built directly with C++17 on Windows wininet.dll and shlwapi.dll. Zero external DLLs or heavy runtime dependencies.

🛡️

Dry-Run Preview

Inspect exact file changes, deletion queues, and total transfer size beforehand with gftp push --dry-run.

📁

Smart Ignore Engine

Parses .gitignore and .gftpignore to automatically exclude node_modules, .git, logs, and sensitive binaries.

📊

ANSI Terminal Visuals

Live progress bars with transfer rates (KB/s, MB/s), ETA estimation, and colorized tabular diff previews.

🤖

CI/CD Release Pipelines

Automate build releases using GitHub Actions for automatic ZIP packaging and dynamic version tracking.

Quick Start Guide

Initialize Configuration

Initialize workspace config using preset target or custom arguments:

# Initialize using built-in target preset
gftp init --preset

# Or initialize with custom FTP credentials
gftp init --host ftpupload.net --user myuser --pass mysecret --remote-dir /htdocs

Test FTP Server Connection

Validate FTP connection, authentication, and directory write access:

gftp test

Check Pending Changes

View files that have been modified or added since your last sync:

gftp status

Execute Differential Sync

Upload modified files with live transfer progress bars:

# Dry-run preview
gftp push --dry-run

# Real differential push
gftp push

CLI Command Reference

Command Arguments Description
gftp init --preset or --host --user Initialize .gftp/config and default .gftpignore file
gftp config show or set <key> <val> View or update configuration settings dynamically
gftp test None Verify FTP server connection, authentication, and directory access
gftp status None Compare local git HEAD against remote commit state SHA
gftp push --dry-run, --force, --all Upload modified files and update remote commit state SHA
gftp sync Same as push Alias for gftp push
gftp log None Display historical synchronization transfer logs
