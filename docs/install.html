Installation & Build Guide

How to install pre-compiled binaries or build gftp from source on Windows.

1. Download Pre-Compiled Binary

Download the latest standalone executable package from GitHub Releases:

Download Latest gftp.exe ZIP

2. Building from Source (MinGW / GCC)

Requires GCC/MinGW-w64 with C++17 support:

# Clone workspace repository
git clone https://github.com/sabbir28/gftp.git
cd gftp

# Build gftp.exe using Makefile
mingw32-make

3. Building with CMake

mkdir build
cd build
cmake ..
cmake --build .
