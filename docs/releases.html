Automated GitHub Actions Release Workflow

Every push to main or release tag automatically triggers the build workflow defined in .github/workflows/release.yml:

1. Triggers on push to main or v* tags
2. Sets up MinGW GCC Toolchain on Windows runner
3. Computes dynamic build version (e.g. v1.0.12)
4. Compiles gftp.exe with -DGFTP_BUILD_NUMBER="v1.0.12"
5. Packages gftp-v1.0.12-windows-x64.zip
6. Publishes GitHub Release with attached binary ZIP asset
